# Sentinel Music Desktop

Десктопное приложение для прослушивания музыки с домашнего сервера Sentinel Music.

## Возможности

- **Удобное воспроизведение:** музыка играет прямо с вашего сервера без необходимости держать открытой вкладку браузера.
- **Работа в фоне:** плеер аккуратно сворачивается в системный трей возле часов и не мешает работе.
- **Управление через трей:** переключение треков, пауза и открытие окна по клику на иконку.
- **Вход без пароля:** быстрый вход по QR-коду или короткому коду сопряжения.
- **Портативность:** есть версия, которая не требует установки и запускается сразу.

---

## Варианты программы

1. **Портативная версия (`Sentinel-Music-Portable.exe`):** просто скачайте и запустите. Ничего устанавливать не нужно.
2. **Установщик (`Sentinel-Music-Setup.exe`):** привычная установка на компьютер с ярлыком на рабочем столе.

---

## Как собрать программу самому

Если вы хотите собрать приложение из исходного кода:

```bash
# 1. Установка компонентов
npm install

# 2. Проверка тестов
npm test
cargo test --manifest-path src-tauri/Cargo.toml

# 3. Сборка приложения
npm run build
```

Готовые файлы появятся в папке `src-tauri/target/release/`.
